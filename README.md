Useful commands
---------------

- Transcription : `npx hyperframes transcribe compositions/assets/chapitre_2_alexnet.mp4 -m large-v3 -l fr --json -o compositions/assets/transcript_chapitre2.json`

- Rendering : `npx hyperframes render . -c compositions/chapitre_2_alexnet.html -o renders/chapitre_2_alexnet.mp4 -q delivery --low-memory-mode`

- Running : `npx hyperframes preview`
